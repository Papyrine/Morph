# Bullets.ttf

A tiny TTF (~1.6 KB) containing only the glyphs Morph needs to render DOCX
bullet markers. Embedded into `Morph.dll` and registered with the font
resolver under the family name **`Morph Bullets`**.

## Why it exists

Word's default bullet template uses Microsoft's proprietary **Symbol**,
**Wingdings** and **Courier New** fonts to draw bullet glyphs (the dot, the
hollow `o`, the small square, etc.). Those fonts:

- Are not bundled with Linux distributions and cannot be redistributed under
  Microsoft's EULA.
- Are loaded by Word via the per-numbering-level `<w:rFonts>` declaration.

If Morph fell back to whatever was on the host (e.g. Arial), the resulting
bullets came out visibly *smaller* than Word's — Arial's `U+2022` glyph is
roughly 0.25em, Symbol's bullet is 0.45em.

`Bullets.ttf` solves this by providing correctly-weighted glyphs at the
Unicode codepoints the parser remaps the PUA bullet characters to (see
`DocumentParser.GetNumberingInfo` and the PUA→Unicode map below it).
Because it ships embedded, it is available on every platform with no host
font dependency.

## Glyph coverage

| Unicode | Char | Used for | Source |
| --- | --- | --- | --- |
| U+006F | `o` | Word's level-1 sub-bullet (literal lowercase `o` in Courier) | Noto Sans Mono |
| U+2022 | `•` | Filled round bullet (Symbol ``, `` fallback) | Noto Sans Symbols 2 |
| U+25A0 | `■` | Filled square (Wingdings ``, ``) | Noto Sans Symbols 2 |
| U+25AA | `▪` | Small filled square | Noto Sans Symbols 2 |
| U+25C6 | `◆` | Filled diamond (Symbol ``) | Noto Sans Symbols 2 |
| U+25CB | `○` | Hollow circle (Symbol ``) | Noto Sans Symbols 2 |
| U+25CF | `●` | Filled circle (Symbol ``) | Noto Sans Symbols 2 |
| U+2713 | `✓` | Checkmark (Wingdings ``) | Noto Sans Symbols 2 |

Both source fonts are **SIL OFL 1.1** licensed. The OFL only requires the
font carry its license metadata (the `name` table copyright/licence records
are preserved by `pyftsubset`).

## How to rebuild

The font is regenerated by `tools/build-bullets-font.py` from the upstream
sources. Run from the repo root:

```bash
pip install fonttools
# Download upstream sources (not vendored):
#   https://fonts.google.com/noto/specimen/Noto+Sans+Symbols+2
#   https://fonts.google.com/noto/specimen/Noto+Sans+Mono
python tools/build-bullets-font.py \
    --noto path/to/NotoSansSymbols2-Regular.ttf \
    --mono path/to/NotoSansMono-Regular.ttf \
    --out  src/Morph/EmbeddedFonts/Bullets.ttf
```

The script subsets each source to its needed codepoints, drops optional
tables that don't appear in both fonts (`vhea`, `vmtx`, `GPOS`, etc.) so
`fontTools.merge` can combine them, merges into a single TTF, and renames
the family to `Morph Bullets`.

When adding a new bullet codepoint mapping in
`DocumentParser.GetNumberingInfo`, also add the codepoint to
`SYMBOL_LIKE_CODEPOINTS` in the script and rebuild.
