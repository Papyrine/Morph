# Bullets.ttf

A tiny TTF containing only the glyphs Morph needs to render DOCX bullet
markers. Embedded into `Morph.dll` and registered with the font resolver
under the family name **`Morph Bullets`**.

## Why it exists

Word's default bullet template uses Microsoft's proprietary **Symbol**,
**Wingdings** and **Courier New** fonts to draw bullet glyphs (the dot, the
hollow `o`, the small square, etc.). Those fonts:

- Are not bundled with Linux distributions and cannot be redistributed under
  Microsoft's EULA without scrutiny.
- Are loaded by Word via the per-numbering-level `<w:rFonts>` declaration.

Earlier versions of `Bullets.ttf` substituted Noto Sans Symbols 2 outlines.
That kept the build OFL-clean but the Noto bullet glyph is roughly
0.25em wide vs Symbol's 0.45em, so the rendered bullets came out visibly
*smaller* and *thinner* than Word's. `Bullets.ttf` is now built from the
actual MS faces, with each source glyph remapped from its PUA / Symbol-encoded
codepoint onto a standard Unicode codepoint - so at runtime the renderer
looks up `U+2022` etc. and gets a glyph whose visual weight matches Word.

## Glyph coverage

| Output Unicode | Char | Used for | Source font | Source codepoint |
| --- | --- | --- | --- | --- |
| U+006F | `o` | Word's level-1 sub-bullet (literal lowercase `o` in Courier) | Courier New | 0x6F |
| U+2022 | `•` | Filled round bullet (Symbol `·` PUA) | Symbol | 0xF0B7 |
| U+25A0 | `■` | Filled square (Wingdings) | Wingdings | 0xF06E |
| U+25AA | `▪` | Small filled square | Wingdings | 0xF0A7 / 0xF076 |
| U+25C6 | `◆` | Filled diamond (Symbol) | Symbol | 0xF0D8 |
| U+25CB | `○` | Hollow circle (Symbol) | Symbol | 0xF0A8 |
| U+25CF | `●` | Filled circle (Symbol) | Symbol | 0xF06C |
| U+2713 | `✓` | Checkmark (Wingdings) | Wingdings | 0xF0FC |
| U+25B8 | `▸` | Small right triangle (drawn) | synthesized | — |
| U+25BA | `►` | Right pointer (drawn) | synthesized | — |
| U+2610 | `☐` | Legacy FORMCHECKBOX unchecked (drawn; box ≈1.15em dipping below baseline, matching Word's field rendering) | synthesized | — |
| U+2612 | `☒` | Legacy FORMCHECKBOX checked (drawn) | synthesized | — |

## Licensing

Symbol, Wingdings and Courier New are owned by Microsoft / Monotype. The
output `Bullets.ttf` is a subset of those outlines remapped onto Unicode
codepoints. Whether redistributing such a subset is permitted depends on
the per-OS font EULA - check before publishing.

## How to rebuild

The font is regenerated by `tools/build-bullets-font.py` from the system
copies of Symbol / Wingdings / Courier New. Run from the repo root on
Windows (the source fonts ship with the OS at `C:\Windows\Fonts`):

```bash
pip install fonttools
python tools/build-bullets-font.py \
    --symbol    C:/Windows/Fonts/symbol.ttf \
    --wingdings C:/Windows/Fonts/wingding.ttf \
    --courier   C:/Windows/Fonts/cour.ttf \
    --out       src/Morph/EmbeddedFonts/Bullets.ttf
```

The script subsets each source to its needed glyphs, rewrites the cmap so
the surviving glyphs sit at standard Unicode codepoints, drops optional
tables that don't appear in all three fonts (`vhea`, `vmtx`, `GPOS`,
`kern`, `EBLC`, ...) so `fontTools.merge` can combine them, merges into a
single TTF, and renames the family to `Morph Bullets`.

When adding a new bullet codepoint mapping in
`DocumentParser.MapBulletPuaToUnicode`, add a corresponding entry to the
appropriate `*_GLYPHS` dict at the top of `tools/build-bullets-font.py`
and rebuild.
